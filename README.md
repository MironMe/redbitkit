# RedBitKit

A colorful, original retro-inspired block puzzle you can play in your browser without creating an account.

## Play locally

Open `index.html` in a modern browser. Your high score, bits, and unlocked block styles are saved locally in that browser using `localStorage`.

## Publish with GitHub Pages

1. Open this repository on GitHub and tap **Settings**.
2. Tap **Pages** in the **Code and automation** section.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then tap **Save**.
5. Wait for the deployment, then open the Pages URL shown on that screen (usually `https://mironme.github.io/redbitkit/`).

## Features

- Responsive, account-free block puzzle with score and local best score.
- Bits earned by placing blocks and clearing lines.
- Color collection with rarity labels, a cosmetic shop, and mystery packs bought with earned in-game bits (no real-money purchases).
- A room-code UI prototype. Real online multiplayer requires a server and is not included in this static GitHub Pages demo.

RedBitKit is an original fan-made concept and is not affiliated with other games.
